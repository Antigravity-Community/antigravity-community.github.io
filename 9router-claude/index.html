💡 چرا این روش مشکل ریجن را حل می‌کند؟

کاربران ایرانی هنگام استفاده از سرویس‌های کدنویسی و مدل‌های هوش مصنوعی گوگل معمولاً با خطاهایی مثل Location not supported یا خطای احراز هویت ریجن مواجه می‌شوند. این خطا ناشی از تنظیمات کشور ثبت‌شده روی اکانت است و تغییر پروفایل مالی در گوگل پیمنت نیز در بسیاری از مواقع آن را حل نمی‌کند.

چرا نیازی به تغییر ریجن یا گوگل کلاد نیست؟

ابزار متن‌باز 9Router پروتکل ارتباطی رسمی Antigravity را روی لوکال‌هاست شبیه‌سازی می‌کند. زمانی که شما از داخل پنل ۹Router وارد جیمیل خود می‌شوید، توکن‌های معتبر صادر شده و سهمیه رسمی مدل‌های Gemini و Claude مستقیماً به سیستم شما متصل می‌شود، بدون اینکه لایه‌های سخت‌گیرانه ریجن اکانت مانع اتصال شوند.

۱. مرحله اول: پیش‌نیاز و نصب Node.js

برای اجرای ۹Router در سیستم، به بستر Node.js (نسخه ۱۸ یا بالاتر) نیاز دارید. اگر از قبل نودجی‌اس را نصب دارید، می‌توانید از این مرحله عبور کنید.

  • ویندوز و لینوکس: وارد وب‌سایت رسمی nodejs.org شوید و نسخه LTS را دانلود و نصب کنید.
  • مک (macOS): با دستور brew install node در ترمینال یا دانلود مستقیم فایل نصب از سایت رسمی.

برای اطمینان از نصب بودن نودجی‌اس، دستور زیر را در ترمینال یا CMD وارد کنید:

Terminal / CMD 
node -v
npm -v

۲. مرحله دوم: نصب و اجرای ۹Router روی سیستم

ترمینال سیستم خود را باز کرده و با استفاده از دستور زیر، بسته ۹Router را به صورت سراسری (Global) روی سیستم نصب کنید:

Install 9Router 
npm install -g 9router

پس از پایان نصب، برای روشن کردن سرور لوکال کافیست دستور زیر را اجرا کنید:

Start Server 
9router

با این کار، سرور پروکسی ۹Router روی پورت محلی 20128 آماده به کار می‌شود و در خروجی ترمینال آدرس پنل به شما نمایش داده می‌شود.

۳. مرحله سوم: لاگین اکانت جیمیل در Antigravity

این مهم‌ترین بخش برای دریافت سهمیه و خنثی کردن خطای ریجن است. مراحل زیر را با دقت انجام دهید:

  1. مرورگر سیستم خود را باز کرده و وارد آدرس http://localhost:20128 شوید.
  2. از منوی کناری سمت چپ، روی گزینه Providers کلیک کنید (آدرس مستقیم: http://localhost:20128/dashboard/providers).
  3. کارت Antigravity (دارای آیکون موشک نارنجی) را پیدا کرده و روی آن کلیک کنید تا وارد صفحه تنظیمات آن شوید.
  4. روی دکمه آبی‌رنگ + Add Account یا Login with Google کلیک کنید.
  5. یک تب جدید از صفحه رسمی ورود گوگل باز می‌شود. جیمیل شخصی خود را انتخاب کرده و رمز عبور را وارد نمایید.
  6. در صفحه درخواست دسترسی‌ها (Permissions)، روی دکمه Allow (تایید و ادامه) کلیک کنید.

نتیجه موفقیت‌آمیز

پس از تایید دسترسی، به طور خودکار به پنل ۹Router بازمی‌گردید. اکنون نام و آدرس جیمیل شما در لیست اکانت‌ها با وضعیت Active (سبز رنگ) درج شده است.

۴. مرحله چهارم: ساخت و کپی کلید API

برای اینکه کلاینت‌های خارجی (مانند ابزار Claude Code یا ادیتورها) اجازه اتصال به سرور ۹Router را داشته باشند، به یک کلید API محلی نیاز است:

  • در پنل وب ۹Router وارد مسیر Settings > API Keys شوید.
  • می‌توانید کلید از پیش ساخته‌شده پیش‌فرض (که با sk-... شروع می‌شود) را کپی کنید یا با دکمه Create API Key یک کلید اختصاصی بسازید.

۵. مرحله پنجم: اتصال به Claude Code در ترمینال

حالا می‌خواهیم ابزار رسمی و محبوب Claude Code در ترمینال، به جای سرورهای پولی Anthropic از ۹Router و سهمیه فعال‌شده اکانت جیمیل شما استفاده کند. برای این کار دو راه وجود دارد:

روش اول: تنظیم پایدار در فایل شل (پیشنهاد جامعه)

فایل پروفایل ترمینال سیستم خود را باز کنید (در مک فایل ~/.zshrc و در لینوکس یا ویندوز فایل ~/.bashrc):

Terminal 
nano ~/.zshrc

چهار خط زیر را به انتهای فایل اضافه کرده و ذخیره نمایید (به جای مقدار کلید، API Key مرحله ۴ را بگذارید):

~/.zshrc 
# هدایت ترافیک Claude Code به سرور 9Router محلی
export ANTHROPIC_BASE_URL="http://localhost:20128"
export ANTHROPIC_AUTH_TOKEN="کلید_API_شما"

# تنظیم مدل‌های پیش‌فرض روی سهمیه رایگان آنتی‌گرویتی
export ANTHROPIC_DEFAULT_SONNET_MODEL="ag/claude-sonnet-4-6"
export ANTHROPIC_DEFAULT_OPUS_MODEL="ag/claude-sonnet-4-6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="ag/gemini-3.8-flash-medium"
export API_TIMEOUT_MS="600000"

سپس برای اعمال تغییرات در ترمینال جاری دستور زیر را بزنید:

Reload Shell 
source ~/.zshrc

روش دوم: تنظیم خودکار از منوی ترمینالی ۹Router

اگر دستور 9router را در حالت منوی تعاملی باز کرده‌اید، می‌توانید وارد مسیر CLI Tools > Claude Code شوید، گزینه ⚡ Quick Setup را بزنید و مدل Sonnet را روی ag/claude-sonnet-4-6 تنظیم نمایید.

۶. مرحله ششم: مدل‌های فعال و تست نهایی

اکنون همه چیز آماده است! وارد هر پوشه پروژه‌ای که می‌خواهید بشوید و دستور رسمی کلود را اجرا کنید:

Run Claude Code 
claude

همچنین برای یک تست سریع و دریافت پاسخ مستقیم می‌توانید دستور زیر را اجرا کنید:

Quick Prompt 
claude "سلام! مدل فعال و وضعیت سیستم را به صورت خلاصه بگو."

جدول مدل‌های فعال آنتی‌گرویتی در ۹Router

نام مدل در ۹Router مدل واقعی کاربرد و ویژگی
ag/claude-sonnet-4-6 Claude 3.7 / Sonnet Thinking قدرتمندترین مدل کدنویسی با استدلال عمیق، بدون هزینه اشتراک
ag/gemini-3.8-flash-medium Gemini 2.5/3 Flash فوق‌العاده سریع و کم‌مصرف برای سوالات و تسک‌های روزمره
ag/gemini-pro-agent Gemini 3.1 Pro Agentic مدل مناسب برای وظایف چندمرحله‌ای و معماری پروژه

استفاده در ادیتورهای دیگر (Cursor / Roo Code / Cline / VS Code)

علاوه بر Claude Code، می‌توانید در هر ادیتوری ارائه‌دهنده را روی OpenAI Compatible قرار دهید، مقدار Base URL را برابر با http://localhost:20128/v1 بگذارید و یکی از مدل‌های جدول بالا را انتخاب کنید.

۷. عیب‌یابی و نکات تکمیلی

۱. خطای پورت در حال استفاده (Port 20128 in use)

اگر ۹Router از قبل در پس‌زمینه در حال اجرا باشد، پورت اشغال است. در مک یا لینوکس می‌توانید با دستور زیر پروسس قبلی را ری‌استارت کنید:

Restart 9Router 
pkill -f 9router || true
9router

۲. اتصال چند اکانت برای سهمیه بیشتر (Account Pool)

شما می‌توانید در همان صفحه Providers > Antigravity چندین جیمیل مختلف را متصل کنید. ۹Router به صورت خودکار ترافیک را بین اکانت‌های شما تقسیم (Load Balance) می‌کند تا هیچ‌وقت با ریت‌لیمیت مواجه نشوید.

۳. پرسش، پاسخ و رفع اشکال در جامعه تلگرام

اگر در حین نصب یا اتصال با سوالی مواجه شدید، می‌توانید در سوپرگروه گفت‌وگوی تلگرام جامعه آنتی‌گرویتی مطرح کنید و آخرین اخبار، راهکارها و ابزارها را در کانال رسمی (@antigravity_iran) دنبال نمایید.
