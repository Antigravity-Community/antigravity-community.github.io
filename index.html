آموزش گام‌به‌گام و جامع

راهنمای صفر تا صد: راه‌اندازی ۹Router، اتصال جیمیل و استفاده در Claude Code

حل قطعی مشکل ریجن ایران در استفاده از هوش مصنوعی گوگل و اتصال سهمیه رایگان مدل‌های Antigravity به ابزار خط فرمان Claude Code در ترمینال.

۱
پیش‌نیاز: نصب Node.js و npm

ابزار ۹Router روی بستر نودجی‌اس اجرا می‌شود. اگر نودجی‌اس روی سیستم شما نصب نیست:

  • از وب‌سایت رسمی nodejs.org آخرین نسخه پایدار (LTS) را دانلود و نصب کنید.
  • در مک می‌توانید با پکیج منیجر Homebrew دستور brew install node را اجرا نمایید.
node -v npm -v
۲
نصب سراسری و اجرای ۹Router

ترمینال سیستم (در مک و لینوکس) یا CMD / PowerShell (در ویندوز) را باز کنید و ۹Router را به صورت سراسری نصب و اجرا نمایید:

# نصب سراسری ۹Router npm install -g 9router # اجرای سرور محلی 9router

با اجرای این دستور، سرور پروکسی محلی روی پورت 20128 سیستم شما فعال شده و آماده اتصال می‌گردد.

۳
لاگین اکانت جیمیل در Antigravity (حل مشکل ریجن)

برای دور زدن محدودیت ریجن نیازی به تغییر کشور اکانت گوگل یا ساخت پروژه در گوگل کلاد نیست؛ ۹Router پروتکل احراز هویت را شبیه‌سازی کرده و سهمیه رسمی را فعال می‌کند:

  • در مرورگر خود آدرس http://localhost:20128 را باز کنید.
  • از منوی سمت چپ (Sidebar)، وارد بخش Providers شوید.
  • کارت Antigravity (آیکون موشک نارنجی) را پیدا کرده و روی آن کلیک کنید.
  • روی دکمه + Add Account یا Login with Google بزنید.
  • در تب رسمی باز شده از گوگل، جیمیل خود را انتخاب و پسورد را وارد کنید.
  • در صفحه مجوزها، دکمه Allow (تایید / ادامه) را بزنید تا توکن ذخیره شود.

پس از تایید، به طور خودکار به پنل ۹Router هدایت می‌شوید و وضعیت اکانت شما در وضعیت فعال (Active) قرار می‌گیرد.

۴
دریافت کلید API از پنل ۹Router

برای اتصال کلاینت‌ها و ادیتورها به ۹Router نیاز به یک کلید احراز هویت محلی دارید:

  • در پنل وب وارد مسیر Settings > API Keys شوید (آدرس: http://localhost:20128/dashboard/settings).
  • روی دکمه Create API Key بزنید یا کلید از پیش ساخته‌شده پیش‌فرض (با شروع sk-...) را کپی کنید.
۵
اتصال مدل‌های Antigravity به Claude Code

برای اینکه دستور رسمی claude در ترمینال، تمامی درخواست‌ها را به جای سرورهای پولی Anthropic از ۹Router و سهمیه رایگان جیمیل شما ارسال کند:

روش اول (تنظیم مستقیم فایل کانفیگ شل): فایل پروفایل شل سیستم خود را باز کنید (در مک ~/.zshrc و در لینوکس یا ویندوز ~/.bashrc) و خطوط زیر را به انتهای آن بیفزایید:

# هدایت کلاینت کلود به 9Router لوکال export ANTHROPIC_BASE_URL="http://localhost:20128" export ANTHROPIC_AUTH_TOKEN="کلید_API_کپی_شده_از_مرحله_قبل" # تنظیم مدل‌های پیش‌فرض روی سهمیه آنتی‌گرویتی export ANTHROPIC_DEFAULT_SONNET_MODEL="ag/claude-sonnet-4-6" export ANTHROPIC_DEFAULT_OPUS_MODEL="ag/claude-sonnet-4-6" export ANTHROPIC_DEFAULT_HAIKU_MODEL="ag/gemini-3.8-flash-medium" export API_TIMEOUT_MS="600000"

سپس در ترمینال دستور source ~/.zshrc (یا source ~/.bashrc) را بزنید تا تغییرات اعمال شود.

روش دوم (تنظیم خودکار از منوی ترمینالی ۹Router): اگر دستور 9router در ترمینال باز است، وارد منوی CLI Tools > Claude Code شوید، گزینه ⚡ Quick Setup را انتخاب کنید و مدل Sonnet را روی ag/claude-sonnet-4-6 بگذارید.

۶
تست نهایی در ترمینال و مدل‌های در دسترس

حالا در هر پروژه‌ای در ترمینال، دستور claude را اجرا کنید یا یک دستور مستقیم بفرستید:

# اجرای محیط تعاملی کلود claude # یا ارسال پرامپت تستی مستقیم claude "سلام، مدل فعلی شما چیست؟"

مدل‌های فعال آنتی‌گرویتی در ۹Router:

  • ag/claude-sonnet-4-6 : مدل قدرتمند و محبوب Claude Sonnet با تفکر عمیق (Thinking) بدون نیاز به هزینه اشتراک
  • ag/gemini-3.8-flash-medium : سریع‌ترین و بهینه‌ترین نسخه Gemini برای پرسش و پاسخ‌های روزمره
  • ag/gemini-pro-agent : مدل Gemini 3.1 Pro Agentic برای کدنویسی‌های پیچیده و مهندسی پروژه

همچنین می‌توانید از همین اندپوینت در افزونه‌های VS Code، ادیتور Cursor، Roo Code و Cline با Base URL برابر با http://localhost:20128/v1 و مدل‌های فوق استفاده کنید.
