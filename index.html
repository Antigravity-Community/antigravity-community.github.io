Antigravity Account Switcher

تغییر آنی و زیر ۳ ثانیه‌ای بین بی‌شمار اکانت گوگل بدون نیاز به لاگ‌اوت و ورود مجدد. امنیت ۱۰۰٪ آفلاین و محلی.

  • پشتیبانی از چیپ‌های Apple Silicon و Intel در مک
  • نسخه نیتیو ویندوز ۱۰ و ۱۱ بدون نیاز به پیش‌نیاز
  • ذخیره‌سازی امن در Keychain و Credential Manager
git clone .../antigravity-account-switcher

مانیتورینگ لایو

Antigravity Quota Monitor

نمایش زنده و درون‌برنامه‌ای سهمیه باقی‌مانده و زمان دقیق ریست شدن مدل‌ها (Claude 4.6 و Gemini 3.8) درست مانند Claude Code.

  • تزریق نشانگر سهمیه مستقیم روی سلکتور مدل‌ها
  • پایداری در برابر آپدیت‌های رسمی (Update-Proof)
  • محاسبه مصرف هفتگی (Weekly Quota) با دیمن سبک
python3 sync_daemon.py

مدیریت سهمیه با MCP Codebase

جلوگیری از اتمام سهمیه و ریت‌لیمیت‌ها با ایندکس ساختاری سورس‌کد پروژه و ارسال هوشمند فقط بخش‌های مرتبط به مدل.

  • تبدیل کدهای پروژه به درخت ساختاری (AST Graph)
  • کاهش بیش از ۸۰٪ مصرف توکن در هر پرامپت
  • جلوگیری از پر شدن ریت‌لیمیت‌های روزانه و ساعتی
npx @modelcontextprotocol/server-filesystem

تبدیل به API استاندارد

استفاده از قدرت مدل‌های آنتی‌گرویتی در ابزارهای خارجی مانند Cursor، Claude Code، OpenCode، VS Code یا CLI ترمینال.

  • ایجاد اندپوینت سازگار با OpenAI / Anthropic
  • بدون نیاز به پرداخت دلاری برای کلیدهای API مجزا
  • پشتیبانی از استریم و اجرای ابری یا لوکال
